# Dior Perfume Experience

A cinematic, scroll-driven web experience that tells a perfume story through full-screen visuals, smooth transitions and interactive sections. Unofficial concept design, not affiliated with Dior.

🔗 **Live demo:** https://lnkd.in/dN8_xuZE

## Tech Stack
- **React** for component-based UI
- **TypeScript** for type-safe code
- **Vite** for fast builds and development
- **CSS** for custom layouts, animations and transitions

## Features
- Chapter-based storytelling structure across the page
- Responsive layouts that adapt to different screen sizes
- Interactive UI components with seamless transitions
- Visuals created with AI generation tools and refined to match a luxury aesthetic

## How I Built It
I built this project in Visual Studio Code using React, TypeScript and Vite. I designed the page as a series of chapters and focused on smooth transitions and a consistent luxury look. AI tools helped generate the visual assets, while I handled the layout, styling and interactions in code.

## Run Locally
```bash
npm install
npm run dev
```
